# RedMemory audio placeholders

Inspector slots are prepared for `RedMemory_Story_BGM` and `RedMemory_Gameplay_BGM`.

Gameplay SFX slots are prepared for `FragmentCollect`, `KeyCollect`, `PlayerJump`, `PlayerLand`, `PlayerHurt`, `PlayerRespawn`, `MissionOpen`, `PhotoOpen`, `MemoryReward`, and `ChapterClear`.
